Leonida Platinum Atlas — a GTA VI trophy guide and tracker covering all 55 trophies (1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden), word-for-word the official list. Per-trophy guide cards with type, missable and online flags, phase and unlock notes; progress tracking with offline saving and export/import; a six-phase platinum roadmap; a missables watch list; spoiler-safe filters; and a Next Up planner that suggests what to chase next.

## Run it

```sh
node serve.ts
```

Serves `app/` at http://localhost:8080. To write the entry dossier: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
